# Pixel Jadecraft（像素琢玉）项目计划

更新时间为 2026 年 11 月 10 日，首版交付目标日期为 **2026 年 11 月 30 日**。

## 已确认的设计

采用 Phaser 4.2.1、Vite 8.3.7 和 JavaScript ES Modules，制作浏览器运行的 2D 像素玉文化游戏。核心流程为 **采矿 → 鉴赏 → 三阶段加工 → 定制 → 图鉴收录 → 展厅陈列**。

| 模块 | 首版交付范围 |
| --- | --- |
| 矿洞 | 1 张地图、6 个矿点、2 类玉材 |
| 鉴赏 | 观察热点、知识提示、6 道题 |
| 工坊 | 玉璧、玉鱼佩、玉印，三阶段加工 |
| 定制 | 3 类纹样、配色、祝福语、图片导出 |
| 图鉴 | 6 个器物条目、文化说明与来源 |
| 展厅 | 1 个等距房间、3 个可布置展位 |
| 基础系统 | 菜单、背包、任务、本地存档、声音设置 |

以上完整七模块及数量已获用户确认。课程知识融入各模块，具体知识文案与来源需在制作时核验。

## 当前完成情况

- 已建立 Vite 工程并安装 Phaser。
- 已配置开发、构建与预览命令。
- 已把环境就绪场景替换为菜单及工坊、矿洞、展厅基础画面，支持地点切换与返回。
- 已建立公共游戏状态、12 格原石背包、委托进度面板和暂停。
- 已实现本地单档自动保存、继续游戏、覆盖确认、JSON 导入导出及损坏存档提示。
- 已实现按钮提示音、静音和音量设置。
- 已通过状态规则测试及基础浏览器交互检查，生产构建通过。
- 已保存设计与任务书。

基础系统已完成第二轮加固，其余六个玩法模块待实现。工坊加入独立生成的像素背景与场景入口，背包改为分类、格子选择及右侧详情，图鉴复用此面板。预加载、菜单、工坊、矿洞和展厅采用独立 Phaser 场景，弹窗与后台状态合并管理暂停。新增快捷键、全屏、声音偏好独立保存、检查点备份恢复及保存失败重试。

矿洞与展厅仍为程序绘图预览；矿点、加工、鉴赏与展柜尚不可交互。图鉴有六个器物的入口、插图和收录状态，知识正文及来源待核验。加工中状态字段暂时只接受空值，后续随加工规则加入有效结构与校验，不宣称已支持加工中断恢复。

用户明确采用“先搭建基础框架，再逐项做功能”的顺序。本轮止于基础系统，下一步实现矿洞移动、碰撞和原石采集；不同时铺开全部玩法。正式美术、场景声音及完整主线仍在后续范围内。

## 开发顺序

1. 建立菜单、场景切换、公共游戏状态、背包和存档基础。
2. 实现矿洞移动、交互采集与材料入包。
3. 接入鉴赏热点、知识提示和题目反馈。
4. 实现琢形、雕纹、抛光三个加工步骤及成品结算。
5. 实现纹样、配色、祝福语与图片导出。
6. 将成品接入图鉴、展厅陈列与任务进度。
7. 先完成一件玉器从采集到展出的完整流程，再补齐七模块的全部数量。
8. 补齐正式美术、声音和知识来源，完成主线及边界场景验证。

## 待细化的规则

- 矿洞操作方式、矿点恢复和采集资源规则。
- 琢形容差、雕纹交互、抛光覆盖率、完成阈值及评分公式。
- 三类纹样的具体内容、祝福语长度和导出图片规格。
- 背包容量、加工中断处理、自动保存时机及存档恢复行为。
- 问答与任务完成条件的关系。
- 主线故事、引导文案和成品展签。
- 课程对 AI 功能、说明文档与演示材料的具体要求。

这些规则应在实现前形成明确默认行为，并在试玩中调整。后续修改已确认的模块与数量时，应更新本计划和验收范围。

## 验证重点

- 从主菜单开始，完成一次采矿、鉴赏、制作、定制和展出。
- 验证材料与成品数量、重复点击、阶段返回和连续制作。
- 验证鼠标快速移动、缩放坐标、释放和离开画布后的交互状态。
- 验证刷新读档、声音设置、图片导出和新游戏覆盖确认。
- 在 Chrome 与 Edge 检查主要页面、中文显示及流程。
- 每次交接记录已实现功能、验证结果和已知问题。
- 交付前执行 `npm run build`，并检查构建后的运行表现。
