## 本轮深化执行

用户明确授权自行取舍、调用 agent/skill、按需安装工具，优先“做好、做深，再做多”。已实施六纹样部件的实际组合导线，玉印白文/朱文与试印返雕，旧玉保养/另作伴佩两路线及回访，三类观众对展签顺序与讲述重点的不同反馈；矿洞加入观察、工具取舍、精准缝口、同源双石追踪与可下穿木栈道；新增原创场景合成音乐和交互音效、独立音量及 UI 分组。

保留现有六簇十二石和三种器型。大型程序生成矿区、可进入的玉中山水和更多内容扩张延后，先验证本轮连接与操作体验。现有依赖足够，没有新增第三方运行依赖。最终 134 项测试、生产构建和浏览器流程通过；详见[深化版验收记录](validation/2026-11-15-depth/REVIEW.md)。视觉继续参考原概念图及新增三张创意图，未宣称达到 95% 相似度。未提交或上传 GitHub。

## 已确认的设计

采用 Phaser 4.2.1、Vite 8.3.7 和 JavaScript ES Modules，制作浏览器运行的 2D 像素玉文化游戏。核心流程为 **参观寻灵感 → 采矿 → 观察玉料 → 设计纸样 → 琢形、雕纹与浮雕、抛光 → 落款 → 图鉴与主题陈列**。

| 模块 | 首版交付范围 |
| --- | --- |
| 矿洞 | 1 张地图、6 处玉脉簇共 12 块玉、2 类玉材 |
| 鉴赏 | 圆窗放大、侧光/透光示意、原石特征、两布局对照，保留6道知识题 |
| 工坊 | 玉璧、玉鱼佩、玉印，真实表面三阶段加工及同 ID 返工 |
| 定制 | 制作前选择3类纹样及表面意图；成品落款、图片导出；旧作保留原配色 |
| 图鉴 | 6 个器物条目、文化说明与来源 |
| 展厅 | 保留个人3展位；追加四分厅文化馆、16件玉材与名作、故事及灵感册 |
| 基础系统 | 菜单、背包、任务、本地存档、声音设置 |

原完整七模块及数量保留。2026-11-15 用户进一步授权增加中国名玉、名作和背后故事、像素化展示，以及更有创造力的玉雕与其他环节。本轮已实施首批扩展，详细完成/部分/未做边界见[修改任务书 R00–R15](REVISION_TASKBOOK_2026-11-14.md#6-开发任务清单)。知识文案保留机构来源；馆藏创作练习属于游戏设计，不作为历史事实。

## 矿洞正式素材替换契约

- 地形完全由运行时生成。Tiled 导出 `public/maps/mine.tmj`，有限 60×32 正交地图，tilewidth/tileheight=16。仅保留嵌入 tileset 元数据和 spawn 对象层；不再读取 ground/walls/decor/oreNodes/ladders。旧布局格式会明确报错并使用默认生成器。
- 一个嵌入 tileset，firstgid=1，margin/spacing=0，至少五帧。五类 kind 属性为 AIR / DIRT / STONE / JADE_VEIN / BEDROCK；对应 hardness 为 0 / 2 / 3 / 3 / 0。kind 映射稳定 tile ID，帧顺序可通过元数据调整。当前加载器要求每项声明唯一类型。
- spawn 中仅一个 PlayerSpawn 点对象，采用脚底锚点。默认逻辑坐标 (80,416)，显示坐标乘 2；不使用矩形中心点。
- LibreSprite 人工导出透明 PNG、等距网格、行优先、margin/spacing=0：`src/assets/tiles-mine.png` 为 16×16、至少五帧；默认依次 AIR/DIRT/STONE/JADE_VEIN/BEDROCK，AIR 透明且不绘制。`src/assets/player-32x48.png` 为 32×48 共18帧，左/右/下各六帧，前四行走、后两挥镐。角色显示比例 1.5，碰撞盒24×56。
- 缺席或加载失败使用五类程序像素地形及矿工，保留已有矿洞背景。三份人工资源当前均未提供。素材可由代理自行寻找，必须核验授权及是否符合概念图01；本阶段没有引入第三方资源。
- 运行时新增素材后重启开发服务或重新构建。合成 TMJ 测试已经通过，正式人工文件仍待验证。

## 设计来源

矿洞的唯一视觉基准采用 1024×559 的 01 图，方向为侧视横版、深蓝灰岩与苔藓、中央洞口冷光、两侧石柱、青绿自发光玉脉、木矿车，以及戴矿灯帽的矿工举镐和碎屑粒子。01 用于确定氛围、元素清单与配色，正式 tileset 按素材替换契约独立生产。[01 矿脉探索与原石采集](concept-art/01-mine-exploration.png)

正式素材替换轮次按顺序采用岩壁 #2B3A42 / #4A5A62、苔藓 #3E6B45、玉光 #4FC98A / #7FE3B0、木 #8B5A2B、底 #101C1B、字 #E8DCC0。洞口冷光在 01 原图以左上角为原点取样 (560, 160)，确定为 #8AABA9。v3.1 程序地形已使用上述岩壁、苔藓与玉光主色，土层另用暖棕与基岩区分；旧角色辅助色保留。

01 的 HUD 为顶部 HP / JADE / LEVEL 状态条、左下三格快捷栏及方向键 / A 按钮。当前已改为顶部状态条与左下三格工具栏，方向操作采用键盘提示；尚未加入触屏方向按钮。

本项目参考星露谷 / 泰拉瑞亚，仅限于资产生产规格（16×16 tile、sprite sheet、四向行走帧、8px 网格）与交互手感（工具动作帧、粒子与音效反馈、热键栏）。题材、配色、中式回纹 UI、等距工坊与展厅仍以概念图 01–10 为准，维持“按原图复刻 / 基础 UI 95% 接近”。矿洞采用侧视横版，参考泰拉瑞亚洞穴探索，配色沿用现有矿洞代码。v3.1 已将可破坏地形与矿灯照明纳入本轮；季节昼夜动态光照与战斗系统继续排除。本轮角色先接入左 / 右 / 下三向帧，上行沿用下向帧。

2026 年 11 月 11 日的视觉与交互访谈结果见[视觉与交互设计框架](../DESIGN_SYSTEM.md)，包括工坊斜视全景与俯视加工近景、工具操作、弹窗暂停、中式等距展厅及三张样稿要求。新增四张参考图见[概念图集](concept-art/README.md)。分辨率、精确组件尺寸、字号与完整色表通过样稿验证后确定。

用户后续明确所有设计按原图复刻，布局、分布与视觉细节作为固定制作基准。最新评审纠正与制作顺序见[设计讨论整理](DESIGN_DISCUSSION.md)，五张静态样稿的状态见[样稿索引](design-drafts/README.md)。
