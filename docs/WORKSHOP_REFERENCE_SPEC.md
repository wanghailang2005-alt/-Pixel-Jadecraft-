## 1. 视觉语言 / Design Tokens

**风格**：中式古典 + 像素艺术（pixel art）。全部硬边、硬描边、无抗锯齿；等距（isometric / 2.5D）房间；木质榫卯框架 + 回纹（雷纹 / Greek key）装饰；暖色宫灯照亮深绿色玉雕工坊。

```css
/* 建议直接落成 CSS 变量；色值为从概念图取色的近似值 */
--bg-deep:        #0B1712; /* 整屏深墨绿背景 */
--wall:           #142A1E; /* 房间墙面 */
--floor:          #2A3A32; /* 地砖 */
--floor-hi:       #34473C;
--panel-bg:       #1E120C; /* 面板深棕近黑 */
--panel-inner:    #241610; /* 内层卡片/标签牌 */
--wood:           #6B4426; /* 木框主色 */
--wood-hi:        #A8743C; /* 木框高光 */
--gold:           #C9A15A; /* 描边 */
--gold-bright:    #E3BE70; /* 标题/高亮 */
--text-cream:     #F0E2C0; /* 正文 */
--text-gold:      #E8B45C; /* 说话人名/强调 */
--text-dim:       #8A7A62; /* 未选中 tab */
--jade-dark:      #1E4D36;

--jade-bright:    #4CB56B;

```

**字体**

- 英文标题 / HUD / 标签：粗像素衬线体，全大写，字距 +1~2px，1px 深色描边（`text-shadow: 1px 1px 0 #000`）。近似可用 Silkscreen / 自定义 bitmap serif；不要用圆滑无衬线。
- 中文匾额「匠心独运」：像素化宋体/楷体，金色。
- 对话正文：米白色粗衬线像素体，带 1~2px 深色描边。
- 必须含 CJK glyph（玉种名称里有中文），否则中文会变成豆腐块。
- 全部文字 `image-rendering: pixelated`，只做整数倍缩放，坐标对齐 2px 网格。

**可复用组件 `OrnatePanel`（三个右侧面板 + 匾额 + 对话框共用）**

1. 双层木框：外层 3px 深棕，内层 1px 金色高光线；面板内侧再留 8px 后有一圈 1px 浅棕内描边。
2. 四角各一个约 16×16 的回纹角花（L 形 Greek key），金色描边。
3. 顶部中央「标签牌」：宽度约面板 55%、高约 28px 的云头/六边形木牌（左右有凹口），压在面板上边框上，上边框在该处断开；牌内居中放金色全大写标题。
4. 面板底色 `--panel-bg`，四周暗角。

## 3. 左侧场景（像素画 / 背景底图）

### 3.1 房间结构

- 深绿墙 `#142A1E`，棕红色斜木梁从顶部中央向左右下方展开成对称「八」字屋檐，形成两面斜切货架墙。
- 斜梁上嵌墨绿色方形装饰板，每块内含浅绿云纹/回纹（左右各 3–4 块）。
- 后墙中央三幅挂屏：中间一幅大（约 60×90）为绿色玉璧（圆环 + 中央方孔 + 螺旋纹），左右两幅窄（约 35×90）为绿色龙纹/云纹竖屏，均深棕框。
- 挂屏上方小匾额「匠心独运」（约 x 295–440, y 78–120）：深棕底、木框、金色字。
- 地面：深灰绿方砖等距斜铺，1px 深色砖缝，砖面有裂纹与噪点。
- 四盏六角宫灯（同一 sprite 复用）：左上 x≈250,y≈150；左中 x≈120,y≈235；右上 x≈475,y≈155；右中 x≈625,y≈235。橙色灯身 `#FFB347` + 红色流苏 + 约 24px 半径的暖黄径向光晕（预烘焙进底图，或用 `mix-blend-mode: screen` 叠加）。

### 3.2 货架与陈设

- **左货架**（斜置多层木架，约 x 110–280, y 170–330）
  - 上层：6–8 根平行斜放的米白圆柱形玉料/卷轴，末端有年轮状断面。
  - 中层：3 块原石（深绿 / 亮绿 / 浅灰白），一个插着木笔的灰色笔筒，一只灰绿高罐在内侧。
  - 底层：三格抽屉木柜，金色小拉手。
- **右货架**（约 x 500–660, y 170–330）
  - 上层：3 件小玉雕（绿色螺旋件、白色笋形立件、绿色环件）。
  - 中层：4 件成品（绿色盘龙环、绿色塔形/瓶形、浅绿坐姿瑞兽等），下方同样三格抽屉木柜。
- **中央工作台**：等距平行四边形木桌，约 x 265–480, y 265–425。深棕桌面带 1px 木纹高光，四边各有银灰金属包角，四条方腿。
  - 桌面：中央一块正在雕刻的绿色玉璧（带孔），周围散落 3–4 个绿色小玉件、刻刀、绿色玉屑与浅绿发光弧形刻痕。
- **老师傅（OLD MASTER）**：约 x 320–390, y 215–305，位于桌后。黑发束髻、浓眉、络腮胡、绿色交领长袍，身体前倾，右手持刻刀向下、左手扶玉料。
- **雕刻反馈**：玉料周围 4–6 个白色/浅绿四角星芒（+ 形 sparkle），2 帧闪烁动画。

## 4. 右侧面板逐项规格

### 4.1 PLAYER HUD

- 顶部标签牌 `PLAYER HUD`。
- 左列三行（~13px 粗体大写）：

### 4.2 INVENTORY & CODEX

- 顶部标签牌 `INVENTORY & CODEX`。
- Tab 栏（两个等宽，各约 48%）：`JADE TYPES` 选中（浅棕高亮底 + 亮米白字 + 下边框与内容区连通的断口）；`TABLES` 未选中（深底 + 灰棕字）。

  1. `1. 羊脂白玉 (Mutton Fat Jade)` — 米白玉珠
  2. `2. 翡翠 (Feicui)` — 亮绿玉珠
  3. `3. 墨玉 (Black Jade)` — 墨绿玉珠
- 底部工具栏：4 个 32×32 方形按钮（间距 ~8px），深棕底 + 金边，图标依次为**放大镜、天平、镐、刻刀**；第一个（放大镜）为当前选中，外圈有 2px 亮绿色 `#8FD46A` 高亮框。
- 交互：点玉种行 → 行底变浅 + 图标高亮；点工具按钮 → 绿色高亮框转移；`TABLES` 切换到纹样/图鉴表。

### 4.3 CRAFTING INTERFACE

- 顶部标签牌 `CRAFTING INTERFACE`。
- 上半区（带 1px 内描边矩形）：
  - 居中 `ENGRAVING`，标题左右各一段水平细线（分隔线在标题处断开）。
  - 下方 48×48 深棕方框内一枚绿色玉璧（环形 + 中心黑孔 + 浅绿斑点纹理），1px 金边。
  - 其下居中 `JADE BI-DISC`。
- 纹样选择：3 个 32×32 方按钮横排（约 64px 间距），每个下方居中标签：
  - `CLOUD` — 白/浅绿云纹排列（3×3 云朵 + 中心圆）
  - `DRAGON` — 绿色盘龙线稿（默认/主推选中，可加亮绿描边）
  - `GRAIN` — 4×4 绿色谷纹点阵方阵
- 进度条：宽约面板 85%，高约 14px，深棕槽 + 1px 金边；填充为亮绿→深绿渐变到 `75%`，未填充部分为深色斜纹；条上叠白色粗体 `PROGRESS: 75%`（带深色描边保证可读）。
- 底部两个并排按钮（各约 45% 宽，高约 30px）：
  - `GENERATE` — 墨绿底 `#2E6E5B`，米白粗体，金色双层边框（主行动，hover 提亮）
  - `BACK` — 酒红底 `#6B2430`，米白粗体，棕红边（返回上一屏）
- 状态机建议：`idle → patternSelected → generating(progress 0→100) → result(更新对话 + 成品进入 FINISHED PIECES)`。

## 6. 交互 / 动画建议

- 全部 UI 整数倍缩放、`image-rendering: pixelated`、坐标对齐 2px 网格；禁用 CSS 平滑过渡位移（只做透明度/亮度）。
- 宫灯光晕 2–3 帧呼吸（opacity 0.75 ↔ 1）。
- 雕刻星芒 2 帧闪烁；选中纹样按钮 1px 亮绿脉冲描边。
- 进度条用 `requestAnimationFrame` 或 CSS `width` 过渡，文字数值同步。
- 悬停：木框按钮亮度 +10%、描边转金色；按下：整体下移 1px。
- Tab 切换 120ms 淡入，不做位移。
