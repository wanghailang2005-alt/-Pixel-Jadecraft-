# Pixel Jadecraft 设计讨论整理

整理日期为 2026 年 11 月 11 日。本文记录本次聊天的设计决定、评审纠正、现有稿件与后续制作依据。详细规范见[设计系统](../DESIGN_SYSTEM.md)，全部参考图见[概念图集](concept-art/README.md)。

## 当前最终要求

用户最新明确“所有设计都要按原图复刻”，随后确认按此要求继续。适用范围覆盖工坊、加工界面、全部场景、侧栏、基础 UI 与弹窗。

原图的构图、组件分布、元素位置、数量、排列、尺寸比例、间距、配色、描边、纹理、装饰与像素颗粒均作为制作基准。用户要求基础 UI 与弹窗达到 95% 的视觉接近程度。验收需要对照实际成品核对，当前样稿尚待按最新要求复核。

制作优先采用原图切片、纹理复用和固定坐标定位。中文与数值在原预留区域动态渲染，显示按整体等比缩放。生成式绘图曾产生构图和材质偏差，后续精确制作以原图素材和代码定位为依据。

## 加工交互与状态

加工流程为切形、雕纹、抛光。玩家点击选工具，按住拖动加工，阶段切换默认选择适用工具。达到要求后提示完成，由玩家选择继续改善或点击下一步。

切形显露轮廓，雕纹显露纹样，抛光移除粗糙层并露出翠色、纹理和局部高光。完成后放大展示成品。打开背包、任务或设置面板时压暗背景并暂停加工，关闭或 Esc 返回。

阶段阈值、评分和动画参数待验证。样稿的加工 50%、工坊预览 75%、音量 60% 均为展示数据。

## 后续制作顺序

1. 从两张组件原图建立切片与原坐标布局，先覆盖基础组件和设置面板。
2. 原位置接入动态中文与实际控件，检查边框、角饰、控件数量和间距。
3. 按对应原图复核工坊及侧栏，并明确加工近景使用的直接视觉基准。
4. 对照检查原尺寸与等比缩放效果，评审后调整精确参数。
5. 将验证后的组件和素材接入已有工程，再继续实现各玩法。
