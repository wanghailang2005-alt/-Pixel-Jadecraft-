# 工坊与设置视觉复核

日期：2026-11-15。参考为仓库原图 07、08、09；本轮未替换为生成样稿。

## 本轮变化

- 工坊右栏恢复 09 的三段结构：玉材区从 196 px 收回 180 px，制作区从 210 px 扩至 230 px；四工具从两行改回单排。图标和中文用途均保留，四个入口继续执行实际操作。
- 原 09 的侧栏铜角与标题端饰以 CSS 定位复用，动态文字、数值、按钮仍为真实 DOM。木板横纹、铜边、高亮/按下/禁用态统一；对白框向左延伸到场景外框，不再与场景框错开一截。
- 师傅从固定凿子和周期闪星改为四个离散像素动作：抬凿、落凿、玉面接触与少量碎屑。凿尖落点对应桌面玉器。使用 Phaser 场景计时器，沿用弹窗、后台、失焦的暂停门；减少动态效果时保持静态接触姿势。
- 设置按 08 形成五行：场景音乐、手作音效、静音、全屏、备份；前两行为横向滑轨，下三行为可用的开关/操作。保留原音量数据及存档规则，无新增设置 schema。备份展开显示完整导入/导出/恢复操作，底部是实际保存与返回。
- 设置按钮和开关复用原图的木铜、米色纸面与折角语言；关闭、键盘焦点、禁用状态仍可见。设置会自动保存，返回按钮不假称撤销设置。

## 浏览器检查

独立 Chrome 会话 `jade-ui-visual`，独立 QA 服务 `http://127.0.0.1:5192/`（禁用热更新，仅为本轮复核）。先前共享开发服务的热更新曾使页面返回主菜单；以下截图均已在独立服务重新取得。

- 1280×900 和 800×700：页面无横向溢出，设置正文无横向溢出；五行、灯笼、底部双按钮完整可达。静音开关实测宽 53 px。
- 通过真实键盘将音乐调到 0%、音效调到 100%，点击静音与保存；刷新后重新打开设置，仍为 0%、100%、静音开启。
- 全屏按钮实际进入与退出全屏，文字随原生 `fullscreenchange` 更新。
- 备份按钮展开/关闭 `details`，导入、导出、立即保存入口可达。未在本轮覆盖旧档或执行恢复操作。
- 工坊四个工具真实点击验证：观玉打开空原石引导、行囊打开空包、琢玉打开开始创作引导、寻玉进入矿洞；没有注入资源。四工具 y 坐标同为 443 px（桌面截图坐标）。
- 打开设置时 `#game[data-paused]` 为 `true`，关闭后为 `false`；动画使用受该暂停门控制的场景计时器。
- 浏览器 `errors` 为空；`node --check src/runtime.js`、`node --check src/ui.js` 和 `git diff --check` 通过。
