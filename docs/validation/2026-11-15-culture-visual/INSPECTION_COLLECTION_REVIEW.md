# 鉴赏与落款的概念图适配

日期：2026-11-15。对照原图 05、06，保留实际原石、加工表面、纸样与存档规则。

## 实际变化

- 鉴赏：移除将大圆镜压缩到 280–320 px 的旧高度规则；1280×900 下镜面为 410 px，大屏上限 480 px。镜框使用离散像素边、铜螺钉与中央刻度，标记仍指向当前原石的真实色斑/色带/细纹。
- 观察台采用 05 的深绿铜边、石墙框与原图玉璧挂饰；观察工具使用已有放大镜、灯笼、玉石小图，而非单个汉字方块。纸卷增加卷杆端头、纸边和浅色纹理；知识来源、两套纸样、创作入口均保留。
- 落款：左侧为米色壳体、深绿内板的作品手记，右侧为原创像素夜窗、灯笼、实体木桌和展座。作品按实际 `base` 边界摆在展座上，仍由统一玉面渲染器绘制，没有替换成固定样图。
- 屏幕使用 `presentation: 'workbench'`；导出时新建独立画布，使用原 `card` 绘图。既有 480×480 绿底作品卡、祝福语和真实刻痕继续保留；展厅默认绘图与 `artifactOnly` 入口不变。

## 验证

独立会话 `jade-ui-visual`、无热更新 QA 服务 5192。载入上一轮通过真实 UI 加工取得的 `2026-11-15-museum-craft/finished-ui-save.json`；本轮没有重新采矿或雕刻，也没有操作用户日常存档。

- 1280×900 和 800×700 均无页面/弹窗正文横向溢出。800×700 的正文可纵向滚动，滚动后观察工具、纸样和开始设计入口可达。
- 真实点击侧光，键盘改变光线、放大倍率、平移，切换透光与留白纸样；选择器型与“带着观察去设计”的通路保持可用。后续设计显示鱼佩与所选原石；本轮未开始消耗材料。
- 祝福语修改为“温润有光，心意长存”并保存，状态层读回一致；与原 fixture 比较，作品 `artisan` 数组和加工结果完全相同。
- 单独调用导出的默认作品卡渲染器，得到有效的 480×480 PNG，见 `collection-card-render.png`；其画面保持原绿底作品卡，没有夜窗/灯笼背景。
- 原生下载按钮已触发 PNG 生成与下载请求，但本轮独立 Chrome 的文件下载被取消，未记录为下载成功。上一轮实际下载证据可用于未更改的下载机制；本轮仅确认独立画布编码、尺寸和表面数据。按钮的 Blob、链接和下载文件名流程未改变。
- `node --check` 检查 `inspection-view.js` 与 `collection-view.js` 通过；本轮浏览器错误输出为空。整体测试与最终构建由主代理统一执行。
