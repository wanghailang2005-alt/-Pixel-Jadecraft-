# 玉材与名器故事扩充：内容与来源

核对日期：2026-11-15。对应 `src/museum-content.js`、`src/museum-narratives.js`。

公共展品由 16 件扩至 28 件：10 个玉材观察条目、14 件历史器物、4 件现代作品。原 16 个 ID 保留，新内容不改变矿区十二块原石、两类可加工材料及存档资源规则。每件新增两段故事，分别从人物、社会用途、地方手艺、发现经历或研究问题进入；材料属性、历史解释和游戏创作练习分别表达。

## 原有展品的故事深化

- 和田玉、翡翠：[GIA 玉史](https://www.gia.edu/jade-history-lore) 支持软玉的史前用途、翡翠在中美洲的文化联系。避免把和田玉商品名称直接等同于特定产地。
- 岫玉：[国家级非遗岫岩玉雕项目](https://www.ihchina.cn/project_details/14005.html)，采用清末民初玉石街、素活与活链技艺、2006年名录信息；没有把所有红山玉器一概认成蛇纹石质岫玉。
- 独山玉：[南京地质博物馆](https://njdzbwg.jsdk.cn/njdzbwg/jcsp/content/DZBWG-JCSP-062.html) 的命名、色彩、地方采掘和顺色制作。该页面关于大玉海的陈述未用于新增文案。
- 良渚玉璧、崧泽玉璜、故宫C形玉龙：沿用既有具体馆藏来源，把已知工痕与工艺整理成易读的故事段落，不新增制作者姓名或具体佩戴者。
- 琮王：[上海博物馆转载的浙江省博物馆藏品说明](https://www.shanghaimuseum.net/mu/frontend/pg/article/id/CI00159328)，采用1986年反山M12:98出土及纹饰记录，具体功用保留分歧。
- 翠玉白菜：[台北故宫藏品页](https://digitalarchive.npm.gov.tw/Collection/Detail/3?dep=U)，采用原为珐琅盆景组成部分、白梗绿叶与虫形的记录；没有加入未经该来源证实的陪嫁故事。
- 大禹治水玉山：保留既有故宫来源及扬州集体制作记录；明确治水是传说题材，讲述协作过程。
- 高冠玉凤佩：[中国国家博物馆](https://www.chnmuseum.cn/zp/zpml/kgfjp/202104/t20210416_249765.shtml) 的佩系孔、商代神鸟观念及贵族佩戴解释，未擅自归为某位墓主。
- 金缕玉柙：[中国国家博物馆](https://www.chnmuseum.cn/zp/zpml/kgfjp/202010/t20201013_247855.shtml) 明确主人为刘修，并有火损经历；不混同刘胜，不把古代不朽信仰表述为功效。
- 四件翡翠国宝：重新阅读馆方的[岱岳奇观](https://old.gmfyg.org.cn/cloud/daguojiangzuo/collection-01.html)、[含香聚瑞](https://old.gmfyg.org.cn/cloud/daguojiangzuo/collection-02.html)、[群芳揽胜](https://old.gmfyg.org.cn/cloud/daguojiangzuo/collection-03.html)、[四海腾欢](https://old.gmfyg.org.cn/cloud/daguojiangzuo/collection-04.html)。以北京玉器厂创作集体署名，分别讲借色山景、套料节材、链条加工和1982—1989年的创作；没有添加未经确认的个人独作署名。
