# 矿洞视觉与动作复核

日期：2026-11-15。基准为 `docs/concept-art/01-mine-exploration.png`，角色与像素语言同时参照 `10-art-and-system-overview.png`。

## 本轮改动

- 连续岩面补入错层裂隙、破碎棱面和确定性颗粒，主岩色使用原图方向的 `#2B3A42 / #4A5A62`。靠真实空洞的岩面较亮，深处未开采岩体逐层变暗；开路后重新计算附近反光。
- 实体边缘增加分簇苔藓、草叶及少量垂根；装饰不参与碰撞。全部十二块矿源、梯井、平台和行走判定保留。
- 梯井加入淡冷光束和远处立柱，落脚处加入暖色小灯；木梯增加钉头，矿车增加铁箍、铆点及木板纹理。
- 矿工增加衣物背带、衣袋、靴面和走路起伏。挥镐不再把工具挤在 32px 角色框内：工具从手部扬起，按本次真实挥击进度落到目标格，重镐和细凿的头部尺寸不同，击中与碎屑闪光同帧发生。暂停清理工具状态。
- 移除原左上 420×130 的画布提示框，改为右上可展开的木铜行记；新档首次实际移动后自动收起，按钮始终能展开。收起后保留目标矿脉、回收数及 R/1/2/Q 快捷键。展开后提供完整路线、材料线索、移动提示和四个可读屏操作按钮，工具选中与展开状态同步到 ARIA。底右重复提示由主界面同步移除。
- 入口增加在真实岩体后面的宽幅冷光与远柱；前景实心岩体仍完全遮挡远景，没有把实体墙画成可走空间。

## 与原图的剩余差距

本轮修复的是材质、光线、道具与人物动作。原图 01 的中央大洞室、宽阔采矿台和石柱构图，与现有六梯井、窄横道地图仍有显著差别；现有位置不能仅靠贴图变成该构图。本轮没有修改地图几何，没有形成可证明的整屏 95% 相似度结果。

提示框现已收拢，主画面保留顶栏与左下三槽。完整还原验收仍需在保留六簇与十二块来源的前提下，对矿洞空间布局继续设计；不以本轮材质和 HUD 改进替代大洞室构图验收。
