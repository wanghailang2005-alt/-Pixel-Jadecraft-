# 工坊局部视觉校准

2026-11-14，Codex 与 Claude Code 协作轮次。此项由 Codex 子代理执行。

## 实现

- 从概念图 09 提取三类玉珠、四工具、三纹样、两原石、两件默认陈列，共十四个图标。按 32×32 网格合并为 224×64 PNG，最近邻缩放并保留透明外边缘。裁切包含图标内的暗底，不含英文标签和白色设计标注。来源为用户提供的 `docs/concept-art/09-workshop-interface.png`，本轮按用户授权复用。
- 在已有 Canvas 图标路径接入图集。图片加载完成后刷新相应图标，加载失败时保留程序绘图回退。材质切换、进度显露及完成后的生成玉璧继续由原有绘图负责。
- 默认成品陈列改用原图的盘龙与玉佩素材。生成作品后显示本次生成的实际玉璧。
- 顶部标题补齐木质牌框，右栏改为硬边多层木铜描边。生命值采用固定尺寸像素心形，空心状态保留。场景内坐标、右栏几何布局和交互沿用已有规格。

复现脚本为同目录 `extract_icons.py`，使用 Pillow。图集坐标及顺序记录在脚本的 CROPS 中。
