# 第二轮可玩主线交接

日期为 2026-11-14。本轮承接用户继续自主推进、参考优秀游戏及增加 Claude Code 分工的授权。

## 已接通的主线

新游戏进入工坊，按师傅提示前往矿洞。采集原石后，返回工坊进行鉴赏答题，选择玉璧、玉鱼佩或玉印，依次完成琢形、雕纹、抛光。成品可以选择三种纹样、三种配色和最多 24 字祝福语，并在展厅的三个展位陈列。

三个加工阶段暂以 75% 覆盖率作为推进门槛。松手保存笔触，关闭或刷新后恢复覆盖区域。该门槛是本轮沿用打磨小样的实现选择，后续可依据试玩调整。

主菜单的玉璧打磨试玩保留。工坊右栏“生成”仍是会话预览，正式制作通过工作台或上方“制作”进入。
