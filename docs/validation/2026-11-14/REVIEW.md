## 实现

- Claude Code 新增弹窗样式，Codex 集成竖向设置布局、原图 08 的灯笼及回纹角饰。设置仍提供实际已有的声音与存档功能，五行控件与原图数量尚有差异。
- 工坊提取原图 09 的十四个图标，校准标题木牌、木铜硬边面板和像素心形。裁切脚本及坐标见相邻 `../workshop-reference/REVIEW.md`。
- 矿洞补充跟随角色的 96px 矿灯区域，外围压暗 40%，遮罩缓存为低分辨率纹理，避免每帧重建。岩石改为四种确定性变体，保留既有地图和正式素材契约。
- 实际爬梯走查发现上端 y=288 时，横移离井会下落并被主巷地板侧面挡住。梯子上端延长到 y=192，新增六条矿簇梯井的实际移动规则测试。六簇完整浏览器路线尚待走通，主巷穿过梯井时仍需使用跳跃。
- 按用户最新字体反馈接入 Fusion Pixel 12px 简体中文版，统一菜单、工坊、弹窗、加工页面及 Phaser 提示文字。大标题与对白使用 24px，小标签采用 12px。官方来源、版本及许可证见 `src/assets/README.md`。
