# 矿区观察、工具与同源双石验收

日期：2026-11-15。开发服务：`http://127.0.0.1:5185/`。独立浏览器会话 `jminedeep`；与其他验收会话隔离。

## 已完成行为

- `R` 或场景按钮观察近处岩壁，侧灯标出每块玉的实际缝口。上层矿道和远处不能提前观察。记录写入 `mineSurvey`，旧存档默认空记录。
- `1` 细凿：通常 320 毫秒一击，玉脉需三击；观察后瞄准金色缝口的八像素范围，一击取玉。鼠标需实际瞄准，键盘 `E` 提供自动对缝。
- `2` 重镐：520 毫秒一击打开普通石墙；玉脉需三次重击，因此到玉脉应切回细凿。颗粒、挥镐速度和震动区分轻重；系统减少动态效果时省略震动。
- `Q` 切换六处矿脉追踪，展示方向、同源颜色线索与双石回收数。原石、创作中玉料和成品共同计入对应的 `Cn-L/R` 来源；地上待拾取的玉料另行提示。
- `E` 挖开下半墙后会自动转向仍挡住人物头部的上半墙，保证键盘路线可继续。
- 顶层每个既有梯井口增加可下穿木栈道。水平行走不会掉入较早的梯井，`W/S` 仍能上下梯，空格仍能跳跃。未改变任何矿脉坐标、十二块来源、地形生成或存档消耗标记。

## 浏览器真实输入

未注入资源、修改存档或传送角色。

1. 新游戏经入口梯、上层矿道、一号梯到 C1 岩壁；`R` 后保存 `mineSurvey=['C1']`。
2. `2 + E` 打开下格与上格墙；移步后 `1 + E` 依次取回 `C1-L`、`C1-R`。
3. 刷新页面并点击继续旅程，观察记录、两块原石和矿脉消耗状态完整保留。
4. 从入口再次步行上层矿道，横穿 C1 和 C4 梯井口到 C2，下梯后实际 `R` 观察。
5. 鼠标长按 HUD 重镐按钮不会向场景挥镐；点击上下两格石墙打开通道；点击细凿按钮后，实际点中 C2-L 金色缝口，一击取得第三块原石，C2-R 仍留在矿脉。
