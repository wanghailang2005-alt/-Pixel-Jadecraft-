日期：2026-11-15；项目：E:/Pixel_Jadecraft；分支沿用 codex/museum-craft-20261114。本轮在已有未提交工作上继续实现，未回滚既有内容，未提交或上传 GitHub。

## 取舍与实现

用户授权按外部案例研究深化项目，同时优化 UI、音效、音乐和采矿，强调先深后多。本轮沿用 Phaser/Vite 和现有浏览器工具，没有新增运行依赖或付费服务。

| 环节 | 实际完成 |
| --- | --- |
| 采矿 | R 近距离观察标出可命中的金色缝口；1 细凿精准取玉、2 重镐快速开路；Q 追踪同源双石与真实回收数量。顶层可下穿木栈道解决走路不断掉井，E 自动转向挡头的上半墙。六处矿脉、十二石不增加。 |
| 自由拼纹 | 云、水、叶、鱼、山、回旋六部件，最多组合 12 个；实际拖动、键盘微调、旋转、缩放、镜像、复制和移除。玉稿编译成 64×64 导线，成品保存实际笔触。 |
| 玉印用途 | 新组合玉印采用正对方形印面的视角，白文刻线、朱文剔地分别操作；试印采样实际高低面并镜像，可试印后返雕、撤销、重新细磨，再导出印谱。 |
| 旧玉来信 | 阅读旧绳、划痕、信件三条线索；保养路线真实刷掉两处积尘、换绳而保留划痕；伴佩路线选择已完成的真实鱼佩。回访记得处理方式、材料和实际刻出的部件。两路线均可成立，没有新加百分比分数。 |
| 故事策展 | 三张展签可调整顺序，选择记忆或工艺重点；孩子、学徒、赠礼人的反馈依据实际展品/顺序/来信记录变化。只完成保养且无新成品，也能展出故事记录。 |
| UI | 工坊导航按行旅/工艺/系统分组；工具增加名称、主次按钮更清楚；手记、信纸和木铜边框统一。支持 800×700 纵向滚动且无水平溢出。 |
| 声音 | 原创 WebAudio 五声音阶旋律及不同场景音色，含按钮、挖掘、发现、拾取、雕刻、磨玉、落印等；音乐和音效独立音量，首次手势激活，暂停、静音、后台停止。无外部录音素材。 |

保留四分厅与 16 个有来源的公共展示。暂不扩展巨大随机洞室、更多器型或“可进入玉中山水”；先验证当前深度。原图 01–10 仍为既有场景基准，三张新增概念用于扩展交互方向；当前运行画面未完成 95% 相似度验收。

均为独立 QA 浏览器；没有操作日常浏览器存档。

1. 矿洞从新档实际步行/爬梯到 C1，观察、重镐开路、细凿取两石、刷新恢复；再跨前面梯井到 C2，实际鼠标点击缝口取玉，HUD 点击不穿透。见 [矿区深度记录](../2026-11-15-museum-craft/MINE_DEPTH_REVIEW.md)。
2. 六部件实际组合与键盘编辑、琢形、雕纹、白文/朱文试印、返回雕纹、撤销、再抛光、成器与 PNG 真实下载；800×700 不横向溢出。见 [创作与玉印记录](../2026-11-15-creative-depth/REVIEW.md)。
3. 本目录 `story-smoke.mjs`：实际点击三线索、拖动柔刷、换绳、交付、回访、刷新恢复、小窗口、零成品故事策展。**最终生产预览重新通过**。
4. `companion-curation-smoke.mjs`：复用上轮已通过 UI 完成的鱼佩 fixture，验证旧存档迁移、伴佩交付、另一封回访、真实陈列、调换展签/讲述重点、三观众不同反馈和重载；此用例不声称重新采矿或雕刻。**最终生产预览重新通过**。
5. 音频通过实际 Chrome AudioContext 和增益节点检查：无手势不启动，普通制作弹窗保持，真正暂停停止，恢复重启，音乐 0/音效 .67 独立，静音和结束清理。最大音量叠加采样峰值约 .383、未发现削波；这是信号校验，未冒充主观听感评审。
6. 工坊 1280×900 与 800×700，故事弹窗 800×700，均无横向溢出；按钮和下方操作可滚动到达。最终生产页浏览器错误输出为空。

## 试玩

本机生产预览：<http://127.0.0.1:5186/>。若服务结束：

```powershell
npm run preview -- --port 5186 --strictPort
```

先体验 R/1/2/Q 矿洞探索，再在创作面板选六部件组合；玉印选择白文或朱文，在雕纹阶段即可试印。工坊顶部“旧玉来信”可直接进入两路线委托；“我的展厅 → 布置展位”可调展签顺序和倾听观众。

不同端口/浏览器存档独立；通过设置中的 JSON 导出/导入迁移旧档。当前前端服务仅本机可访问，尚未公开部署。
