## 改版目标

师傅赠玉 → 听故事、看玉 → 选型与三阶段加工 → 落款 → 布展与回访。矿洞退出正式玩法。玩家在馆里看清器物，知道它背后的人和事，再把看见的一个细节用到自己的作品里。

## P0｜主线、工坊与玉文化馆

| 编号 | 问题与交付 | 验收 |
| --- | --- | --- |
| 01 | **师傅像站在桌上。** 一起处理人物落脚、桌沿遮挡、俯身、稳玉和落凿。 | 640×700、800×700 检查工坊首屏、进工作台和加工返回。脚落在地面或被桌沿合理遮挡，身体从桌后俯向工作面，稳玉手和落凿时的凿尖与玉料接触。 |
| 02 | **玉石介绍偏材料说明。** 把具体人物、器物用途、生活背景和匠人取舍带进馆藏、原石鉴赏及图鉴。 | 玩家能从一段可追溯的故事找到一个器物细节，并知道怎么把它用于自己的作品。史实、传说和游戏虚构标示清楚。 |
| 03 | **取消矿洞玩法，重接玉料供给。** 新档预置 12 种原石，师傅对白确认第 01 块见面礼；工坊另备四种色带样料。 | 新档只确认一次见面礼，旧档保留收藏并补齐空格，创作无需扣行囊。正式导航没有矿洞和采矿操作。 |
| 04 | **清理旧矿洞引导。** 统一菜单、师傅对白、首展委托、手册、行囊和鉴赏空态、工坊与展厅导航。 | 从新档和旧档进入，各入口都能指向有效下一步；保留的旧玉料来源可以按历史记录展示。 |
| 05 | **迁移旧矿洞存档。** 当前实现方向为矿洞位置回工坊，未拾取掉落弃置。 | 加载、刷新继续、导入备份均覆盖矿洞位置和未拾取掉落；已收藏原石、草稿、作品、展位和故事进度保留。 |
| 06 | **明确工坊首屏主操作。** 区分示例、当前草稿和真实成品，减少重复入口对新手的干扰。 | 未领玉时，师傅对白和主按钮都指向领玉；未开稿时隐藏进度；有草稿时能直接继续；展架示例与成品标识清楚。 |
| 12 | **馆藏近看太粗糙。** 把展柜缩略图和近看精绘分别处理。先做翠玉白菜、良渚玉琮、大禹治水图玉山三个样板。 | 展柜缩略图能认出轮廓。近看和放大能辨认白菜叶脉及色带、玉琮刻纹、玉山的山石和人物层次。新素材记录参考出处和许可，样板通过后再铺开。 |
| 13 | **放大后观察点与器物可能错位。** 当前代码只缩放器物画布，标记仍使用原观察框坐标。 | 常态、放大、侧光都指到同一个细节；未选中标记尽量少遮挡；侧光变化能帮助观察对应部位。 |
| 14 | **馆藏到创作的灵感交接。** 原实现可能回退到其他藏品或自由创作。 | 从未收藏和已收藏展品进入，都能明确带入当前展品或得到下一步说明；先领玉再创作时保留该展品；完成后核对作品关联。 |

## P1｜逐屏体验与交付验收

| 编号 | 问题与交付 | 验收 |
| --- | --- | --- |
| 07 | **加工台小窗拥挤。** 左栏文字断行，右栏说明被截，画布下有多余空白。 | 640×700、800×700 能读完整工具说明，画布有足够空间，保存、撤销和下一阶段容易点到。 |
| 08 | **馆藏故事、工艺选择和展签衔接弱。** 让展签和回访使用玩家实际做过的事。 | 走一条有灵感的创作路线，核对展签是否正确引用参考展品和可追溯的作品选择；覆盖无灵感作品。 |
| 09 | **「我的玉展」和「我的展厅」容易混淆。** 建议馆内改称「我的收藏」，独立展厅保留布展用途。 | 玩家能分辨全部作品与三个正式展位，从作品详情找到陈列入口；窄窗下每件作品和操作对应同一展位。 |
| 10 | **新主线需从头玩到尾。** 用生产预览跑新档及旧档回归。 | 无注入新档走完赠玉、听故事、观玉、三阶段加工、落款、布展、刷新继续和回访。旧档覆盖第 05 项；浏览器里比较两种抛光表面，并检查保存、撤销和返工。 |
| 11 | **复核发布资源和新任务基线。** 检查矿洞背景、地形、矿工图集和运行入口是否还进入发布产物，记录 Phaser 现用场景。 | 查看新构建产物。现行任务书和验收脚本按赠玉主线执行，历史矿洞证据可继续追溯。 |
| 15 | **主菜单主次不清。** 首次、继续、参观和系统入口堆在同一列。 | 新档一眼看到「开启旅程」，存档状态下容易找到「继续旅程」；首次游玩提示在主按钮附近。 |
| 16 | **馆藏总览缺少明显起点。** 展柜和铭牌像背景，入门导览在底部。 | 展柜有可辨认的点击态、悬停和键盘焦点；初次进入能直接选一件代表藏品开始看。 |
| 17 | **馆藏详情的故事、观察与操作分散。** 把故事段落与器物细节连起来，让收藏和创作入口易找。 | 窄窗能看懂该看哪里、如何继续和从哪里收藏；滚动提示与操作反馈清楚。 |
| 18 | **空行囊和空展厅先展示大块占位内容。** 把下一步放到首屏。 | 空行囊能找到赠玉或工坊选料入口；空展厅根据有无成品显示制作或选择陈列的操作。 |
| 19 | **落款页预览和表单相隔太远。** 缩短编辑、预览、保存与导出之间的距离。 | 640×700 编辑祝福语能看到关键预览，保存后可直接导出；试印和重新设计有清楚的次级入口。 |
| 20 | **旧玉来信读完线索后，下一步不够明确。** 让选择处理方式和实际操作紧接线索。 | 800×700 完成第三条线索后能直接找到两条路线。保养时鱼佩、清理位置和操作提示可同时查看。 |
| 21 | **跨场景字号、对比度和按钮层级不统一。** 覆盖常驻导航、弹窗和实际游戏操作区。 | 640×700 正文和辅助文字可读。主动作、返回、关闭、禁用、焦点和按下状态容易区分。 |
| 22 | **场景之间的美术精细度差异大。** 用工坊人物与桌面、馆藏近看、成品陈列与纪念卡三个样板统一轮廓、光源和材质层次。 | 样板在实际游戏中并排复核。之后检查馆内游客、旧玉鱼佩、试印手部反馈及纪念卡装饰等细节。 |
