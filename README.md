# Pixel Jadecraft（像素琢玉）

基于 Phaser 的 2D 像素玉文化游戏，计划串联采矿、鉴赏、玉器加工、纹样定制、图鉴和数字展厅。

## 当前状态

截至 2026 年 11 月 10 日，已建立基础框架：主菜单、新游戏覆盖确认、工坊／矿洞／展厅入口、公共状态、12 格原石背包、委托进度面板、暂停、提示音设置和本地单档。提供 JSON 备份导入／导出、存档校验与错误提示。

画面使用 960×540 逻辑分辨率、像素采样和窗口等比例适配。工坊使用参考概念图生成的独立背景，人物、入口、HUD 与面板分层；矿洞及展厅仍是程序绘图预览。矿洞移动与采集、鉴赏、三阶段加工、定制和布展尚未实现；入口中的说明面板不代表对应玩法完成。背包初始为空，委托不会因切换场景而完成。

第二轮基础系统增加了独立 Phaser 场景生命周期、弹窗／后台暂停、物品选择详情、原石／成品／图鉴分类、全屏和快捷键。保存失败保留本次进度并支持重试；每次覆盖有效存档前保留上一份检查点，可在设置中确认恢复。声音偏好独立保存，损坏的游戏存档不会因菜单调整音量被覆盖。页面关闭前如有未保存进度，浏览器会按自身规则提供离开提示，建议主动导出备份。

## 技术环境

- Phaser 4.2.1
- Vite 8.3.7
- JavaScript ES Modules
- 已验证的本地工具为 Node.js 24.14.0 与 npm 11.9.0

依赖版本以 `package-lock.json` 为准。

## 本地运行

在仓库目录安装锁定依赖并启动开发服务。

```powershell
npm ci
npm run dev
```

在浏览器打开终端输出的本地地址，默认端口为 5173。服务运行期间保持终端开启，端口占用时以 Vite 实际输出为准。

## 构建与预览

```powershell
npm run build
npm run preview
```

执行 `npm test` 可验证存档读写、检查点恢复、导入失败保护、背包容量与重复结算、任务判定及暂停组合等状态规则。快捷键：B 行囊、J 委托、G 图鉴、M 静音、F 全屏、Esc 暂停或关闭面板；弹窗打开时不会触发场景快捷键。关键状态自动保存，刷新后从主菜单选择“继续旅程”。存档只保存在当前浏览器和当前站点地址下，不同端口或浏览器不共享进度。

构建产物位于 `dist/`。预览服务会输出可访问的本地地址。正式部署可将构建产物交给静态托管服务。

## 主要文件

| 路径 | 用途 |
| --- | --- |
| `index.html` | 页面入口与基础样式 |
| `src/main.js` | 公共状态、界面与运行时的组装 |
