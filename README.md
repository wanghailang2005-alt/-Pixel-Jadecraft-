# Pixel Jadecraft（像素琢玉）

基于 Phaser 的 2D 像素玉文化游戏。在博物馆寻找灵感，观察亲手采回的玉料，再用刻线、浮雕和局部光泽做出自己的作品。

## 试玩主线

1. 开启旅程，参观“玉文化馆”的山川藏玉、千年玉事、匠心天工和我的玉展。近看展品，读故事，观察细节后收藏灵感。馆内包括和田玉、翡翠、岫玉、独山玉、良渚玉琮、红山玉龙、翠玉白菜和四件翡翠国宝等内容；“我的玉展”可分类查看亲手采回的原石和作品。
2. 前往矿洞，用 A/D 行走、W/S 爬梯、空格跳跃，鼠标或 E 挖掘。狭窄通道需要挖开头部与脚部的岩石；满包时玉料留在矿洞，腾出空间后可以回来拾取。
3. 在“鉴赏”圆窗中放大、移动侧光或查看透光示意，比较同一原石的两套纸样；六道知识题保留为可展开的知识卡。
4. 从工作台或“创作”进入正式玉稿，选择玉璧、玉鱼佩或玉印，确定纹样、纸样位置、方向、尺寸和表面意图。先去余料，再刻纹与降低背景，最后细磨并局部抛亮；三阶段按各自的实际加工结果完成。
5. 随时撤销上一笔、重做本阶段或保存退出。成器后在“落款”留下最多 24 字祝福，导出 480×480 PNG；已有作品可沿用原 ID 返工，取消返工会恢复原作与空出的原展位。
6. 查看“一轮温润的月”“把一条河带回家”“掌心有山川”三个故事委托，可直接前往相关展品或按委托器型与表面意图开始设计。在“我的展厅”摆放三件作品，选择因材成器、山水自然或学徒旅程主题，比较灯光与基于实际作品的展签反馈。

## 规格版玉雕工坊

界面依据用户提供的[工坊复现规格](docs/WORKSHOP_REFERENCE_SPEC.md)及工坊概念图制作，并按用户后续要求中文化。右栏三块分别为学徒状态、玉材与图鉴、玉器制作，按规格坐标定位，左下为可推进的中文打字机对话。桌后人物使用独立生成的黑发绿袍老师傅素材。2026 年 11 月 14 日依据用户对字体的反馈，改用本地 Fusion Pixel 简体中文像素字体，标题与对白采用 24px，紧凑标签采用 12px，系统中文字体作为加载失败时的回退。

可选择羊脂白玉、翡翠、墨玉，切换工具和图鉴页签，选择云纹、龙纹、谷纹。点击“生成”从 0% 推进到 100%，完成后显示本次最近两件玉璧；“返回”可以取消并返回纹样选择。弹窗、打磨近景、切换场景和页面隐藏分别暂停生成计时。导航、行囊、委托和设置位于游戏框上方。点击“玉雕工作台”可进入原打磨练习。

学徒状态的生命、金币、玉屑与等级采用规格演示数值。生成预览、纹样和陈列保留于本次页面会话，刷新或新游戏后重置。正式游戏的材料消耗、经济数值与成品入包由后续规则接入。

旧 v1 存档读取时补全开场字段，继续游戏可直接进入原场景。菜单试玩与工坊练习在切换入口时重置打磨进度，同入口返回重开可保留本次页面的覆盖情况。教学完成记录与正式首展任务分别保存，正式的材料消耗、成品制作与入包随后接入。

## 玉璧打磨试玩

开始界面已于 2026 年 11 月 11 日接入像素山林与楼阁背景、独立绘制的 PIXEL JADECRAFT 标题，以及继续、新游戏、打磨试玩、图鉴、手册和设置菜单。背景来源与生成提示词见[素材说明](src/assets/README.md)。

2026 年 11 月 11 日加入可操作的打磨小样。启动后点击主菜单“试玩玉璧打磨”，或进入工坊点击“玉雕工作台”。按住鼠标或手指拖动绒布，擦除粗糙层并显露翠色与纹样；笔刷大小可调，玉璧内孔与外围排除在覆盖率之外。键盘操作为方向键移动工具、空格打磨。

覆盖率达到暂定的 75% 后可点击“完成打磨”查看作品，也可继续加工至 100%。提供暂停、设置、重新打磨与返回入口。关闭设置后保留原暂停状态，失焦或离开加工区域时结束当前笔触。

试玩进度保留于本次页面会话，刷新后重置。小样使用独立绘制的桌面与玉器纹理，视觉贴近程度、完成阈值和操作手感待试玩评审。正式制作流程中的原石消耗、成品入包与加工存档仍待接入。

## 技术环境

- Phaser 4.2.1
- Vite 8.3.7
- JavaScript ES Modules
- 指定的本地工具基准为 Node.js 22.22.2 与 npm 10.9.7
- 2026 年 11 月 11 日本轮终端实测与验证环境为 Node.js 24.14.0 与 npm 11.9.0

依赖版本以 `package-lock.json` 为准。

## 本地运行

在仓库目录安装锁定依赖并启动开发服务。

```powershell
npm ci
npm run dev
```

在浏览器打开终端输出的本地地址，默认端口为 5173。服务运行期间保持终端开启，端口占用时以 Vite 实际输出为准。

## 构建与预览

```powershell
npm run build
npm run preview
```

执行 `npm test` 可验证存档读写、检查点恢复、导入失败保护、背包容量与重复结算、任务判定及暂停组合等状态规则。快捷键：B 行囊、J 委托、G 图鉴、M 静音、F 全屏、Esc 暂停或关闭面板；弹窗打开时不会触发场景快捷键。关键状态自动保存，刷新后从主菜单选择“继续旅程”。存档只保存在当前浏览器和当前站点地址下，不同端口或浏览器不共享进度。

构建产物位于 `dist/`。预览服务会输出可访问的本地地址。正式部署可将构建产物交给静态托管服务。
